# finance_el

This repository contains a financial digital twin project with a Python backend and React frontend.

## Structure

- `backend/`: FastAPI backend services and simulation logic
- `financial-twin/financial-twin/`: React frontend application
- `screenshots/`: Project screenshot documentation

## Screenshots

The `screenshots/README.md` file contains details about the captured screenshot assets.

## Notes

- Runtime logs and environment files are intentionally excluded from commits.
- Use `backend/README.md` and `financial-twin/financial-twin/README.md` for subsystem-specific setup and usage.
